# Cloudflare 部署與交付清單

原則：**網域、主機、網站都在客戶名下**。你只是被邀請的協作者，交付後可以完全退出。

---

## 一、客戶要準備的（你在旁邊協助，帳號密碼由客戶自己輸入）

- [ ] 用客戶自己的信箱註冊 Cloudflare 帳號，開啟兩步驟驗證
- [ ] 決定網域名稱（例如 `hsinphoto.com`），在 Cloudflare 的「網域註冊」購買，用客戶的信用卡付款
- [ ] 在帳號的「成員」邀請你的信箱（權限給「管理員」即可，不要給「超級管理員」）

## 二、部署網站（你做）

Cloudflare 後台 → Workers & Pages → 建立 → Pages，擇一：

**A. 直接上傳（最簡單，推薦給一次性交付）**

1. 選「直接上傳」，專案名稱例如 `hsin-photography`
2. 把整個網站資料夾拖進去（不含 `.git`）
3. 部署完會得到 `hsin-photography.pages.dev` 網址，先用它檢查

之後要更新，就在同一個專案再上傳一次新版本。

**B. 連接 Git 倉庫（之後常改內容時比較方便）**

1. 把倉庫放到客戶的 GitHub 帳號（可設私人）
2. Pages 選「連接到 Git」，選該倉庫
3. 建置設定：框架「無」、建置指令留空、輸出目錄 `/`
4. 之後推送到 `main` 就會自動更新

> Cloudflare 的介面和名稱偶爾會改（例如 Pages 與 Workers 的入口），以實際畫面為準。

## 三、上線前檢查

- [ ] `js/data.js` 的 `SITE.sheet`、`SITE.form` 已填好，並實際送出一封測試詢問
- [ ] 試算表共用設定是「知道連結的任何人：檢視者」
- [ ] 所有頁面**拿掉** `<meta name="robots" content="noindex">`（原型階段用來避免被搜尋到，正式上線要拿掉）
- [ ] 表單下方的「原型示意」文字已消失（設定 `SITE.form` 後會自動隱藏）
- [ ] 手機實機檢查：首頁首屏動畫、選單、各分類頁、燈箱
- [ ] Pages 專案 → 自訂網域 → 加入客戶的網域（網域在同一個帳號，DNS 會自動設定）
- [ ] 用正式網域開啟，確認有 https 小鎖頭

## 四、交付給客戶

- [ ] 一頁說明：
  - 網域：在哪裡、到期日、是否自動續約
  - 網站：Cloudflare 專案名稱、正式網址
  - 內容更新：試算表連結、怎麼改聯絡資訊與影片
  - 表單：收信服務名稱、用哪個信箱登入
- [ ] 客戶確認一切正常後，從 Cloudflare 成員移除你自己（或保留，若有簽維護合約）
- [ ] 你這邊的 GitHub 原型倉庫改成私人或刪除，關閉 GitHub Pages，避免同一個網站在兩個地方

## 五、費用（實報實銷，寫在報價單上）

|---|---|---|
| Cloudflare Pages 主機 | 免費 | — |

| 表單收信服務 | 免費方案（有每月件數上限） | — |
| Google 試算表 | 免費 | — |
