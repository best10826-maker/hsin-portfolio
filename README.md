# Hsin Photography 作品集原型

靜態網站（HTML / CSS / JavaScript），不需要建置。

- 內容設定（網站設定、聯絡資訊、YouTube 連結、各分類相簿）：`js/data.js`
- 照片：`img/`（壓縮後的 WebP，每張有 `-s`、`-l` 兩個尺寸）
- 本機預覽：`python -m http.server 4173`

兩個功能都是「填了才啟用」：`js/data.js` 最上面的 `window.SITE` 留空時，網站維持原型模式。

## 一、內容試算表：讓客戶自己改聯絡資訊和影片

客戶在 Google 試算表改內容，網站下次開啟時就會更新，不用改程式、不用重新上傳。

### 試算表格式

只用第一個工作表，三欄：

| 區塊 | 名稱 | 內容 |
|---|---|---|
| 聯絡 | Email | hello@example.com |
| 聯絡 | LINE | @hsinphoto |
| 聯絡 | Instagram | @hsin.photo |
| 聯絡 | 電話 | 0900-000-000 |
| 婚禮紀實 | 美福大飯店｜婚禮精華 | https://youtu.be/xxxxxxxxxxx |
| 活動紀錄 | 洄游音樂會｜現場紀錄 | https://www.youtube.com/watch?v=xxxxxxxxxxx |
| 空間與商品 | 台灣巴斯夫｜空間影片 | https://youtu.be/xxxxxxxxxxx |

- **區塊**：填「聯絡」，或有動態作品的分類名稱：活動紀錄、婚禮紀實、空間與商品。
- **名稱**：聯絡資訊填 Email／LINE／Instagram／電話；影片填要顯示的標題。
- **內容**：聯絡資訊本身，或 YouTube 連結（watch、youtu.be、shorts 都可以）。
- 影片照列的順序顯示。某個分類沒有任何影片列時，那一頁會顯示「影片連結待補」。
- 範本：`docs/內容試算表範本.csv`（Google 試算表 → 檔案 → 匯入）。

### 設定步驟

1. 建立 Google 試算表，貼上範本內容後改成真的資料。
2. 右上角「共用」→ 一般存取權改成「知道連結的任何人」、角色「檢視者」。
3. 複製試算表網址，貼到 `js/data.js` 的 `sheet: ''` 引號裡。
4. 推上 GitHub。之後改試算表即可，網站不用再動。

說明：

- 試算表會被任何拿到網址的人看到，**只放本來就要公開在網站上的資訊**。
- Google 可能有幾分鐘快取，改完沒立刻出現是正常的。
- 讀不到試算表時（網路問題、權限沒開），網站會沿用上一次讀到的內容或 `data.js` 裡的內容。
- 也可以用「檔案 → 共用 → 發布到網路」產生的網址。

## 二、詢問表單：真的寄到信箱

用免費的表單收信服務，網站不需要自己的後端。擇一即可：

**Web3Forms**（不用註冊帳號）

1. 到 web3forms.com 輸入要收信的信箱，取得 Access Key（會寄到那個信箱）。
2. 把 Access Key 貼到 `js/data.js` 的 `form: ''` 引號裡。

**Formspree**（有後台可以看歷史訊息）

1. 到 formspree.io 註冊並建立表單，取得網址（`https://formspree.io/f/xxxxxxx`）。
2. 把整個網址貼到 `form: ''` 引號裡。

說明：

- 信件主旨會是「作品集網站詢問：拍攝類型｜稱呼」，內容欄位是中文。
- 對方在「聯絡方式」留 Email 時，收到信可以直接按回覆。
- 表單有隱藏欄位擋簡單的垃圾訊息。
- 免費方案有每月件數上限，實際額度以服務網站為準。
- 設定後記得自己送一封測試，確認收得到（第一次可能要到信箱點確認）。
